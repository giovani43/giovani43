## 🚀 Proyectos en producción

### [MVZ Barbería](https://mvz-barberia.vercel.app) — SaaS de turnos para barberías
> **[frontend](https://github.com/giovani43/barbershop-saas) · [backend](https://github.com/giovani43/barbershop-saas-api)**

Plataforma de reservas online en uso real por una barbería en CABA.

- 💳 **Pagos integrados** — Mercado Pago para cobro de penalidades por inasistencia
- 📲 **WhatsApp automático** — Twilio para confirmaciones, cancelaciones y recordatorios
- 📊 **Dashboard de analytics** — ingresos por día, tasa de no-show, horarios pico (Recharts + SQL agregado)
- 🎫 **QR tickets** — check-in de clientes con escaneo de código QR
- ✍️ **Firma electrónica** — aceptación de T&C firmada digitalmente
- ⚙️ **CI/CD** — deploy automático en Render (backend) + Vercel (frontend) desde GitHub

**Stack:** `Flask` `PostgreSQL` `Supabase` `React 19` `Vite` `Tailwind` `Recharts` `Mercado Pago` `Twilio` `Render` `Vercel`
